## Tooling gaps (recorded, not dropped)

- **Duplicate code** — no duplication detector in Roslyn Indexer; org CodeQL config has no `cs/duplicate-*` rules. Duplication surfaced only via the scout pass (Q1-006, Q1-010).
- **Dead code** — Roslyn Indexer misses invocation edges (verified: calls at `LLamaEmbedder.cs:59/194`, generic-method calls at `LoggingInstrument.cs:124+` absent from the call graph), and DI registrations / `new`-constructor refs are under-modelled. All spot-verified wave-1 candidates (10+, incl. every AI one) are actually used — **zero true dead methods found**. Class is candidate-only until the indexer is fixed.
- **CodeQL hotspots / dead stores** — org CodeQL config does not enable `cs/hotspot-*` or dead-store rules; only the alert stream was available (37 wave-1 alerts in `quality/codeql/wave1-alerts.json`).
- **Unused public surface** — computed in-scope only (36 projects); consumers in other components/org repos not indexed. Entries are candidates, not verdicts.
- **Cyclomatic complexity** — no direct column in the indexer; `complexity.sql` computes a branch-statement proxy (1 + branches).
- **`dotnet run` on this host** — SDK-store runtimes need GLIBC_2.44 (system glibc older); benchmarks run via direct dll execution with `DOTNET_ROOT` at the working nix combined-runtime store (see `metadata.txt` note).
